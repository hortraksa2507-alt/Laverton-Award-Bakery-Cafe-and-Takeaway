## Features

- Responsive single-page design
- Hero with live open/closed status
- Menu highlights (NZ-style pies, savoury, sweets, coffee)
- Customer reviews from Google
- Embedded map and contact section
- Mobile-friendly navigation

## Run Locally

```bash
# Using Python
python3 -m http.server 8080

# Or using Node.js (npx)
npx serve .
```

Then open [http://localhost:8080](http://localhost:8080).

## Deploy

This is a static site — deploy to any static host:

- **GitHub Pages** — push to `gh-pages` branch or enable Pages on `main`
- **Netlify** — drag & drop the folder or connect the repo
- **Vercel** — import the repo, no build step needed
